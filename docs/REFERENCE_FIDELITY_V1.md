# Reference Fidelity V1

The six approved concept boards are visual acceptance references, not literal brand/name specifications.

## Preserve
- monumental editorial serif
- disciplined sans UI
- cream / volcanic black duality
- lava accent
- documentary Kona photography
- isolated product imagery
- tiny tracked metadata
- strong grid/alignment
- generous negative space
- few actions
- calm museum mood

## Do not copy literally
- Canyon Museum as parent identity
- concept navigation where current Home/Discover/Garage/Plan/Me is better
- proprietary/unlicensed typefaces
- decorative coordinates everywhere
- UI implying official Canyon affiliation

## Image roles
- Landing: PLACE + PERSON
- Discover: PLACE / MACHINE / PERSON / STORY
- Artifact: MACHINE
- Garage: MACHINE + OWNERSHIP
- Plan: PLACE
- Me: JOURNEY

## Golden-screen threshold
A screen is visually finished only when:
- hierarchy >= 90
- typography >= 90
- image treatment >= 90
- grid/alignment >= 90
- whitespace >= 85
- CTA clarity >= 95
- brand consistency >= 90
- mobile ergonomics >= 95
- progressive disclosure >= 90
- overall reference fidelity >= 88

Scores are review rubrics, not automated pixel equivalence.

## Required evidence
For Home, Discover, Artifact, Garage, Plan, Me and World:
- 320 light/dark
- 390 light/dark
- desktop light/dark
- exact SHA
- no overflow
- safe area
- AA text contrast
- <=1 dominant CTA
- current navigation state
- no 3D before explicit world entry

## Visual physics
Shell screens should trend from the current text-heavy composition toward image-led composition.
Target is not a fixed 35:65 ratio; imagery must carry semantic meaning and the current task remains dominant.
