# Visual Evidence Review Rubric V3

Every golden surface receives a screenshot and a measured review. A screen is not "good" because it looks polished in isolation.

## Surfaces
Landing · Onboarding · Reveal · Home · Discover · Artifact · Garage · Plan · Me · 3D WALK · 3D INSPECT.

## Device matrix
320×720 · 360×780 · 390×844 · 430×932 · 1440×900.
Light/dark where the surface supports them.
Physical: current Android + iPhone Safari/PWA for release-facing flows.

## Scoring dimensions (0–5 each)
1. 3-second comprehension
2. visual hierarchy
3. typography
4. spacing/rhythm
5. grid/alignment
6. contrast/legibility
7. primary-action clarity
8. navigation predictability
9. progressive disclosure
10. image/object focal quality
11. cross-screen continuity
12. perceived craft/memorability
13. accessibility
14. performance/loading appropriateness
15. task completion / user value

## Hard blockers
- horizontal overflow
- clipped primary content
- JS error
- missing/broken primary CTA
- >1 competing primary CTA in a state
- 3D/hall/GLB/HDR on Landing/Home/Plan/Me/Garage
- text below WCAG AA
- essential pointer target below WCAG 2.2 minimum without equivalent
- critical gesture without deterministic alternative
- room theme alters global navigation semantics
- affiliate economics affect ranking
- user state lost after reload

## Product-level targets
Global shell: calm, familiar, consistent.
Content: distinctive, cinematic, memorable.
Accent: selective; lava for action/selection/progress, reef for information.
3D WALK: world dominant, one context signal.
3D INSPECT: object dominant, one exhibit surface.
Artifact: one dominant action, <=4 hero facts.
Garage: Owned/Dream/Try remain visibly distinct.
Plan: intent-aware, not generic tourist list.
Me: identity + progress + next step, not an empty dashboard.

## Benchmark rationale
- familiar navigation/action patterns
- content-led branding
- progressive disclosure
- strong alignment/grouping
- accessibility as a release requirement
- immersive gestures supplement, never replace, deterministic controls

## Evidence rule
Scores are attached to an exact deployed SHA. Physical-device scores require physical-device screenshots. Concept boards never count as runtime evidence.
