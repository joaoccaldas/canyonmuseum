# Artifact Detail V1

One exhibit language for every product/artifact.

## Above the fold

ARTIFACT 01 / N

Name
year · category · role

[object / image / live 3D]

3–4 key facts

one sentence

[PRIMARY ACTION]
secondary actions

Tabs/sections:
Overview · Engineering · Race History · Gallery

## Rules
- one dominant action
- no more than four hero facts
- 3D is progressive enhancement, not required to understand the object
- sources/provenance available without competing with the hero
- affiliate action is visually secondary and disclosed
- Add to Garage expresses Owned / Dream / Try
- same component supports bikes, shoes, helmets, watches, components and memorabilia
