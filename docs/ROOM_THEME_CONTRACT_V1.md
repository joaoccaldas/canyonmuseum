# Room Theme Contract V1

The shell owns:
- typography
- navigation
- spacing
- interaction semantics
- accessibility
- errors/loading
- cards/sheets
- selected/disabled states

A room owns:
- accent
- ambient light
- material/surface
- light intensity
- fog/atmosphere
- content imagery/sound

A room must not redefine buttons, navigation, type hierarchy or accessibility semantics.

This contract is the migration target for WYLD, Halloween, Sanctuary, Nike, future Breitling studies and athlete rooms.
